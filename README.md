# LabSmartTrack - Lab Animal Colony Management System

### Author: Kailine Lima

####     Milestone 1 — .NET and Angular Foundation
- Create the .NET solution.
- Create the ASP.NET Core Web API.
- Create the Angular application.
- Configure Swagger.
- Configure communication between Angular and the API.
- Create the dashboard layout.
- Add initial xUnit tests.
####     Milestone 2 — SQL Server and Colony Models
- Configure SQL Server.
- Configure Entity Framework Core.
- Create Facility, Room, Rack, Cage, Mouse and Strain models.
- Create database migrations.
- Create RESTful CRUD endpoints.
####     Milestone 3 — Colony Management Interface
- Create Angular models and services.
- Display rooms, cages and mice.
- Create add, edit and delete forms.
- Add validation and error messages.
- Connect Angular components to the REST API.
####     Milestone 4 — Breeding, Litters and Reports
- Create breeding-pair and litter models.
- Add weaning-date calculations.
- Create breeding-management endpoints.
- Build dashboard counts and charts.
- Add health and welfare records.
####     Milestone 5 — Authentication and Administration
- Add ASP.NET Core Identity.
- Add JWT authentication.
- Create login and staff registration.
- Add roles and authorization.
- Create administrator approval and rejection.
- Send applicant email notifications.
- Add authentication and authorization tests.
